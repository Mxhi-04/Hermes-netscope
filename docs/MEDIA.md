## Asset inventory

- `brand/nous-logo.svg`: the filled badge SVG served inline in the [Nous homepage](https://nousresearch.com/) navigation, preserving the original `viewBox` and paths. `brand/nous-logo.png` rasterizes it for the video. The video opens and closes with this emblem.
- `brand/nous-seal.svg`: [Nous light seal](https://nousresearch.com/assets/nous-web/nous-stamp-light.svg), shown as an attributed footer image.
- `brand/nous-mission.webp`: [Nous mission header artwork](https://nousresearch.com/assets/nous-web/mission-reference/mission-header.webp?v=6c8553191f83), used in the editorial cover and first product scene. It is brand artwork, not a product screenshot.
- `readme-hero.png`: original layout composed from the attributed mission art, local fonts, and original copy.
- `report-overview.png`, `report-dns.png`, `report-host.png`: real Chromium captures of the HTML generated by netScope's tools using `examples/make_sample_pcap.py`, seed 42. The report UI itself was restyled to match the new visual direction. No production or personal capture data appears.
- `report-demo.gif`: a real browser capture of the report replaying the same synthetic fixture.
- `demo-poster.png`, `demo-storyboard.jpg`: frames rendered from the actual motion design source.
- `netscope-demo.mp4`: original motion graphics film, 1920×1080, 30 fps, H.264/AAC; under 90 seconds.
- `demo-narration.wav`: generated English female narration from **Sarvam Bulbul v3**, speaker **ishita**, `en-IN`, pace **1.12**, 24 kHz WAV. [API documentation](https://docs.sarvam.ai/api-reference/text-to-speech/convert), [voice recommendations](https://docs.sarvam.ai/api/api-guides-tutorials/text-to-speech/bulbul-v3-best-practices).
- `demo-script.json`, `demo-captions.srt`: narration, scene timing, and captions. Timing is aligned per scene; subtitles are not word-level forced alignment.

The soundtrack uses original, quiet synthesized tones, without third-party samples. The supplied Sarvam key was used only to request narration. No credential is saved in repository source, media metadata, or build inputs. The plugin itself does not call Sarvam.

## Typography

The public reference site's Rules and Aeonik fonts were inspected but are not redistributed. The media instead uses:

- [Anton](https://github.com/google/fonts/tree/main/ofl/anton), SIL Open Font License; see `assets/fonts/OFL-anton.txt`.
- [DM Mono](https://github.com/google/fonts/tree/main/ofl/dmmono), SIL Open Font License; see `assets/fonts/OFL-dm-mono.txt`.

The report uses system fonts so that it remains a single self-contained HTML file. Downloaded brand imagery and marks retain their original owners' rights; the repository's MIT license does not relicense them.

## Reproduce

Runtime analysis needs only Python. Authoring media additionally needs Pillow and an installed `ffmpeg` executable. Install those in a separate development environment; they are not plugin dependencies.

```bash
python3 examples/make_sample_pcap.py sample.pcap
python3 demo.py sample.pcap --report
# Install requirements-media.txt and Chromium for browser captures.
python3 scripts/capture_report.py /absolute/path/from/report_path.html
python3 scripts/render_media.py --stills
python3 scripts/render_media.py --video
```

The committed narration permits rendering without API access. Replacing it with new speech is a separate authoring step requiring your own Sarvam credential. Keep credentials out of source and media. The committed MP4 is linked from the README because GitHub does not play relative MP4 file links inline; the GIF is the inline preview.
